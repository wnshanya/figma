# figma

Статичная вёрстка главной страницы блога **Finsweet** на HTML и CSS.

**[Открыть страницу →](https://wnshanya.github.io/figma/)**

## Что находится на странице

- Шапка с логотипом, навигацией и кнопкой Subscribe.
- Главный блок с фоновым изображением, заголовком статьи и кнопкой Read More.
- Раздел Featured Post с выделенной публикацией.
- Список All Posts с карточками статей.
- Блок About Us / Our Mission.

## Файлы проекта

- [`index.html`](index.html) — структура и содержимое страницы.
- [`style.css`](style.css) — оформление, расположение блоков и эффекты наведения.
- [`src/`](src/) — изображения, логотип, иконки и favicon.

Используются шрифты **Inter** и **Sen**, подключённые через Google Fonts. JavaScript, серверная часть и сборщик не используются.

## Запуск

Скачай репозиторий и открой `index.html` в современном браузере. Сохрани `style.css` и папку `src` рядом с HTML-файлом, чтобы подключались стили и изображения.

Для загрузки шрифтов Google Fonts нужен интернет. Без подключения браузер использует доступный запасной шрифт.

## О проекте

Проект демонстрирует вёрстку страницы блога. Тексты статей служат наполнением макета; переходы на отдельные страницы и оформление подписки не реализованы.
